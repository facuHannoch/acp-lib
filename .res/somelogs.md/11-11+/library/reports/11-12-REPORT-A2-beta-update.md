## Spec changes read for A2 (`library/11-11-SPEC-controller-interface.md`, beta `1bda9ef`)

- `send(run): Promise<void>`. The `HarnessController` reports `turn_started` synchronously inside
  `send` (`sentBySession: true`) and returns an already resolved promise.
- `TurnRun.turnId` is optional. The `HarnessController` requires it (a run without one is an error);
  backend-scheduled controllers ignore it.
- `subscribeTurns` delivers `TurnEvent = TurnStarted | TurnTook`. `turn_took` is never reported by
  the `HarnessController`; the session handles it in B2 (step 5).
- Backend-scheduled queue semantics (the queue operation ends at `send` acceptance; the turn is its
  own operation; no deadlock): B2 behaviour. For the `HarnessController` the turn still runs inside
  the operation that sent it, as today.
